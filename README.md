# Надёжный патчер Lime Gen3: фиксированный 64 KB образ

## Summary

Создать Windows-приложение на Python с tkinter-интерфейсом и CLI-ядром. Оно анализирует любые `.hex`/`.bin`, но запись разрешает только для базового профиля `25 km/h unlocked` с подтверждённым SHA-256 и байтовыми сигнатурами.

Не использовать FPB в рабочей прошивке. Новая логика размещается только в подтверждённом erased-region `0x080084AC–0x0800F7DF`; весь итоговый образ остаётся в `0x08000000–0x0800FFFF`, без увеличения 64 KB payload.

## Core changes

- Поддержка Intel HEX и BIN: checksum, Flash/RAM map, vector table, SHA-256 payload, STM32F103 identification, Thumb disassembly и RE-отчёт.
- Профили JSON с hash, точными hook-байтами, stock-значениями, code-cave range, допустимыми параметрами и rollback-данными.
- Любой неизвестный образ: только анализ и diff с известными образами; экспорт заблокирован.
- Для базового профиля: backup, manifest изменений, повторная проверка HEX/BIN после сборки, запрет записи за `0x0800FFFF`.
- Любой output содержит ровно 65 536 байт payload; патчер отклоняет попытку расширить образ, использовать область boot `0x08000000–0x08000FFF` или затронуть неразрешённые байты.

## Resident shim и RE

- Отдельный ARM Thumb-shim, собранный воспроизводимо и проверяемый дизассемблированием.
- Таблица конфигурации: версия, CRC, stock-параметры, raw-значения, приблизительные `≈ A`, флаги режимов.
- Подтвердить и подключить hook-точки для:
  - boot HIGH → рабочее unlocked-состояние;
  - отключения lock и heartbeat;
  - speed limit и реакции на превышение скорости;
  - zero-start;
  - throttle: Stock / Linear / Two-step;
  - Two-step: Low/High limits и граница 50–90% ручки;
  - brake regen: тормоз активирует рекуперацию, отпущенный газ = максимум, полный газ = ноль;
  - отдельного лимита рекуперации.
- Поля доступны для записи только после доказательства адреса, типа параметра, исходных байтов и безопасного диапазона. До измерения ток отображается как `raw` и `≈ A`, с явной маркировкой приблизительности.

## Windows UI

- Загрузка HEX/BIN, статус профиля, отчёт распознавания, карта Flash и список найденных функций.
- Отдельные вкладки: «Анализ», «Настройки», «Экспериментальный стенд», «История/rollback».
- У каждого поля: текущий raw, `≈ A` при наличии модели, stock-значение, кнопка «Сток», диапазон и уровень уверенности.
- Неподтверждённые поля видны в отчёте, но недоступны для изменения.

## Verification

- Fixture-тесты для базового образа, locked-версии, 20 km/h и 131 KB образа.
- Проверки checksum, hash, hook-байтов, code cave, диапазона Flash, неизменности всех неразрешённых байтов и rollback.
- Тесты shim: Thumb-инструкции, branch/trampoline, сохранность регистров, CRC конфигурации.
- ST-Link проверка: readback SHA-256, UART init/HB, boot от HIGH, zero-start, throttle modes, lock/HB bypass и рекуперация на вывешенном колесе.
- Не считать результат готовым по одному успешному flash: каждый режим подтверждается отдельно.

## Assumptions

- Базовый write-профиль — только текущий рабочий `25 km/h unlocked`.
- Не полагаться на возможные 128 KB у клонов STM32F103C8: считать доступными только штатные 64 KB.
- Существующая работа через ESP и HB используется как контрольная исходная конфигурация и rollback-точка.
